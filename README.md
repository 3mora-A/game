# Rock Paper Scissors

A small browser game built with plain HTML, CSS and JavaScript — no frameworks, no build step. You pick a move, the computer picks at random, and the running score updates.

![Rock Paper Scissors game screen](screenshots/game-screenshot.png)

## Features

- Three move buttons (rock, paper, scissors) with emoji artwork
- Random computer opponent
- Live score tracking for player and computer
- Reset button to clear the score
- Result message after each round

## Tech

| Part | Used |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | Vanilla JavaScript |

## Running it

No install needed — clone and open the file:

```bash
git clone https://github.com/3mora-A/game.git
cd game
```

Then open `index.html` in any browser.

## Project structure

index.html      # markup, styles and game logic
